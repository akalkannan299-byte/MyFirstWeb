CAMPUS BITES — COLLEGE CANTEEN FRONTEND

Files
-----
index.html  Main website structure
style.css   Layout, colors, responsive design and print styling
script.js   Menu, cart, student details and bill functionality

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the extracted "college_canteen_frontend" folder.
3. Double-click index.html to open it in Chrome, Edge or Firefox.
4. No Node.js, server, database or installation is required.

FEATURES
--------
- Home page and navigation
- Student name, year and phone number form
- Snacks and meals menu
- Breakfast, lunch, dinner and juice category filters
- Add items and change quantities
- Automatic subtotal, discount and tax calculation
- Demo payment type selection: UPI, Card or Cash
- Bill generation with student and order details
- Print bill button
- Responsive layout for desktop and mobile screens

IMPORTANT
---------
This is a frontend-only educational demo built with HTML, CSS and JavaScript.
It does not save orders permanently, connect to a database, or process real
UPI/card payments. The payment type is only recorded on the generated bill.
The 5% discount applies when subtotal is greater than ₹300. A 5% tax is
calculated after discount.
